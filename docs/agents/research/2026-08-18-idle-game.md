# Research: a small idle game

## Goal
A tiny, **low-attention** game two people can dip into during office jobs — progresses on its
own, rewards the occasional glance/click, and needs no sound or focus. Shared between the
couple via the app's existing sync.

## Constraints & feasibility (from the codebase)
- **Vanilla JS, no build.** Build DOM with `el()`; all logic in one commented section of
  `app.js`; view + sidebar button in `index.html`; styles in `styles.css`.
- **Offline-first progress is easy.** `Date.now()` is already used (`app.js:474/535/2045`) and
  there's a 20 s `setInterval` tick (`app.js:2691`). An idle game stores a **`lastTick`
  timestamp**; on load / each tick it awards `rate × (now − lastTick)` and updates `lastTick`.
  So progress accrues even with the tab closed — the core idle payoff — with zero backend.
- **Sync fits the standard pattern.** New state under `org.idle`, added to `SYNC_KEYS`
  (`app.js:1248`) and reloaded in `applyRemoteState`. Realtime already propagates changes with
  an echo guard (`_by`).
- **Per-device option exists** too (`org.nick`, `org.canvasview` are deliberately *not*
  synced) — useful if each player wants their own save.
- **Two-player model + badges** already exist (raids seed two players; `setBadge`/
  `updateBadges`) — reusable for a co-op or head-to-head framing and a sidebar counter.
- **Naming:** there's already a **"Games to Play"** tab (a backlog of real games). The idle
  game is distinct — it gets its **own sidebar view** (e.g. an "Arcade"/game-named tab).

### The one real design question: co-op vs. competitive (affects sync)
- **Co-op (one shared save):** cutest for a couple, but if both tabs are open and idle at once,
  each could award offline gains from the same `lastTick` → mild double-count, and
  last-write-wins could drop the odd click. For a casual toy that's acceptable; mitigations:
  make accrual authoritative from the shared `lastTick`, keep clicks additive.
- **Competitive / parallel (each has their own save):** each player's state is separate
  (keyed per person), so **no write contention** — simplest and robust — plus a friendly
  "who idled more this week" comparison. Slightly less "together".
- A clean middle ground: **separate saves + a shared leaderboard/among-us goal.**

## Idle-game archetypes considered
Clicker/incremental (Cookie-Clicker), idle tycoon (numbers-go-up + upgrades + prestige),
tamagotchi/idle pet, idle garden/farm, cooperative goal-filler. Filtered for *low attention*,
*office-appropriate (silent, glanceable, pausable)*, and *nice with 2 players*.

## Proposals (4 concrete concepts)

### A. "Our Garden" — idle garden (co-op, calm) ⭐ recommended
Sunlight accrues over time (even offline). Spend it on seeds; plants grow through stages on a
timer; harvest for coins; buy more plots and rarer plants. You both tend one shared garden.
- **Loop:** glance → plant/water/harvest → close. Offline growth is the reward.
- **Why it fits:** calm, on-theme (pink/green), genuinely low-attention, clear cute MVP.
- **MVP:** 1 plot type, sunlight rate, 3 plant tiers, harvest→coins→buy plot; offline catch-up.

### B. "Break Room" — idle coffee/office tycoon (numbers-go-up)
Coffee brews per second; spend beans on upgrades (better machine, more baristas); optional
prestige ("new franchise") for a multiplier. Classic satisfying incremental with office humor.
- **Why it fits:** maximally ignore-friendly, very "office", the dopamine of growing numbers.
- **MVP:** 1 currency, a big brew button, ~5 upgrades, offline earnings.

### C. "Desk Pet" — idle tamagotchi (cute, minimal)
A little creature earns coins/XP over time and **evolves** through forms; you feed/pet it once
in a while. One shared pet you both raise.
- **Why it fits:** minimal attention (feed occasionally); evolutions are the payoff; adorable.
- **MVP:** pet with level + a passive coin, feed button, 3 evolution stages.

### D. "Launch Together" — cooperative weekly goal (ultra-light)
You both passively (+ occasional clicks) fill a shared bar toward a goal (build a rocket /
reach a milestone) that **resets weekly** — echoing the app's weekly-raid rhythm. Cosmetic
milestones as you go.
- **Why it fits:** the lowest-attention option; purely cooperative; tiny scope.
- **MVP:** shared progress bar, passive fill + click boost, weekly reset, 3 milestone art states.

## Recommendation
For a couple's calm office toy, **A ("Our Garden")** is the sweet spot: on-theme, genuinely
low-attention, clear MVP, and co-op. **B ("Break Room")** is the pick if you want the classic
"numbers go up" dopamine; **C** if you want maximum cute; **D** for the lightest possible.
